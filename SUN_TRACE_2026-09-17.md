# Backspace trace for the apparent sun reflection

The user wants genuine surface reflections preserved and rendered correctly in stereo, with camera-style lens flares removed. The prior capture showed a bright spot on glass in one eye and on a neighboring gray building in the other. Its producing draw was not captured, so it is not yet positively identified as either effect.

## Diagnostic

`src/sun_trace.inl` adds a one-frame ordered trace after Backspace, around all four game draw entry points. It records color-writing draws on targets at least 512x256, without the old shader whitelist, depth gate, or per-shader occurrence limit. Each scope includes the complete original draw and both eye draws; internal duplicates are excluded from recursion.

Before/after thumbnails are copied on the GPU into a page containing 64 pairs. Pages are saved as `mevr-suntrace-PID-CAPTURE-PAGE.png`, alongside the usual log/capture files. Output pages are 1024x1024: tiles are 128x64, eight columns; each pair is consecutive even/odd tiles. Partial pages have unused black tiles. Format changes flush the current page. The cap is 2048 eligible draws; reaching it produces an explicit truncation message. Present saves the final page. Lost-device/reset paths release the atlas without attempting a readback.

Matching `.bin` pages contain a 16-byte header (four little-endian uint32s: magic 0x53554E31, version 1, record byte size, record count), followed by `SunTracePage::Record` structures from the source. These preserve draw order, shader hashes, draw route, primitive count, target dimensions/format, blending/depth settings, suppression status, viewport, VS c0..127, PS c0..63, texture bindings and 2D dimensions, and HRESULTs for constant reads and both thumbnail copies. Shader bytecode is saved for up to 512 unique shader pairs independently of the old capture budget. A bound texture is evidence only if the shader samples it.

The existing selective full-size before/after capture remains available. This new trace closes gaps between its selected draws; thumbnail resolution may require a targeted higher-resolution follow-up once the producing draw is identified.

No capture device calls occur outside the marker frame. The diagnostic may pause gameplay when Backspace is pressed. No game render targets, viewport, shaders or render states are changed by the new trace. The atlas is at most 32 MiB for the current HDR scene format, released after each page/frame or on reset.

## Flare settings

- `LensFlares = off` retains the three previously identified camera-flare material filters.
- New `NativeLensFlareSuppression = off` leaves native components available for diagnosis, so the suspected reflection is not preemptively removed. It defaults off. Setting it on restores the previous broad component shutdown when LensFlares is off.
- This does not establish that every remaining flare-like effect is a reflection. The next capture must identify its shader and contribution before a selective stereo fix is made.
